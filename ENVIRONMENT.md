# Environment Configuration

Copy `.env.example` to `.env` and adjust. **Never commit `.env`** (it is
git-ignored) and never put secrets in source code or Docker images.

## Variables

| Variable | Required | Default | Purpose |
|---|---|---|---|
| `DATABASE_URL` | yes (dev) | dev compose URL | Prisma connection string. In the production compose stack it is assembled automatically from the `POSTGRES_*` values and points at the `db` service. |
| `AI_API_KEY` | no | empty | Anthropic API key. Empty → the deterministic demo AI provider runs everything offline. Set → live Claude API with automatic fallback to the demo provider on failure. |
| `AI_MODEL` | no | `claude-opus-5-5` | Claude model used when `AI_API_KEY` is set. Calls time out after 30 s and fall back to the demo provider; outputs are schema-validated. |
| `MOCK_AI_LATENCY_MS` | no | `450` | Artificial "thinking" delay of the demo provider (0 disables it; tests use 0). |
| `OPERATOR_USERS` | **prod** | empty | Comma-separated `name:scrypt.<salt>.<key>` logins. Create entries with `./scripts/add-operator.sh <name>` (host) or `npm run auth:hash -- <name> <password>`. Empty (with `SESSION_SECRET`) disables sign-in — development only; `deploy.sh` refuses to deploy without it. |
| `SESSION_SECRET` | **prod** | empty | HMAC key for operator session cookies (12 h). Generated by `add-operator.sh`. Rotating it signs everyone out. |
| `NEXT_PUBLIC_APP_URL` | no | `http://localhost:3000` | Public base URL. |
| `PUBLIC_BASE_URL` | prod | empty | Externally reachable `https://` base URL; Twilio webhook signatures are validated against it. |
| `DOMAIN` | prod | empty | Public hostname. Enables the `tls` compose profile (Let's Encrypt via certbot, nginx HTTPS). |
| `LETSENCRYPT_EMAIL` | with `DOMAIN` | empty | Contact address for certificate expiry notices. |
| `UPLOAD_DIR` | no | `./uploads` | Where uploaded documents are stored. In Docker this is the `taap_uploads` volume at `/app/uploads`. |
| `MAX_UPLOAD_MB` | no | `10` | Per-file upload limit. nginx caps request bodies at 15 MB (90 MB for multi-file claim packs). File types are checked from the content, not the browser's label. |
| `POSTGRES_USER` | prod compose | `taap` | Database user for the production container. |
| `POSTGRES_PASSWORD` | **prod compose** | — | Database password. Compose refuses to start without one; `deploy.sh` also refuses the `change_me` placeholder. |
| `POSTGRES_DB` | prod compose | `taap` | Database name. |
| `AUTO_SEED` | no | `true` | `true`: seed the demo data when the database is empty (first boot). `always`: restore the canonical demo records on every start. `false`: never seed. |
| `HTTP_PORT` / `HTTPS_PORT` | no | `80` / `443` | Host ports nginx binds to. |
| `BACKUP_RETENTION_DAYS` | no | `7` | Days of nightly database dumps kept on the host. |
| `IMAGE_TAG` | deploy | `latest` | Set by `deploy.sh` to the commit being deployed; images are tagged `taap-app:<sha12>`. |
| `E2E_BASE_URL` | tests only | `http://localhost:3000` | Target for `npm run test:e2e`. |

### Voice agents (xAI Grok Voice)

| Variable | Required | Default | Purpose |
|---|---|---|---|
| `XAI_API_KEY` | for voice | empty | xAI key. Without it, browser voice and phone agents are unavailable; everything else works. |
| `XAI_VOICE_MODEL` | no | `grok-voice-3.0` | Pinned voice model (not `grok-voice-latest`, which xAI migrates automatically). |
| `XAI_REALTIME_URL` | no | `wss://api.x.ai/v1/realtime` | Realtime endpoint (tests point it at a fake). |
| `GATEWAY_SECRET` | prod | `SESSION_SECRET` | Signs voice-session tickets, Twilio stream tickets, upload links and app→gateway calls. |
| `VOICE_GATEWAY_PUBLIC_URL` | dev | empty | Where browsers reach the gateway in development (`ws://localhost:8080`). Empty in production: same origin under `/ws/` via nginx. |
| `VOICE_GATEWAY_INTERNAL_URL` | dev | `http://voice-gateway:8080` | How the app reaches the gateway (answering-machine notifications). Compose sets it. |
| `APP_INTERNAL_URL` | dev | (empty) | How the gateway reaches the app for work it can't do itself (re-sending a Letter of Guarantee renders its PDF). Compose sets `http://app:3000`; empty runs it in-process (tests, the probe). |
| `VOICE_DEBUG` | no | (empty) | `1` logs every voice-model event except audio, with tool arguments. |
| `VOICE_GATEWAY_PORT` | no | `8080` | Gateway listen port. |

### Telephony (Twilio)

| Variable | Required | Default | Purpose |
|---|---|---|---|
| `TWILIO_ACCOUNT_SID` / `TWILIO_AUTH_TOKEN` | for phone | empty | Twilio credentials. The auth token also verifies every webhook signature. |
| `TWILIO_PHONE_NUMBER` | for phone | empty | The hotline / caller ID (E.164). Shown on the Call Center page. |
| `PUBLIC_BASE_URL` | for phone | empty | `https://<domain>` — webhook URLs and signature checks are built from it. |
| `ON_CALL_DOCTOR_NUMBER` | no | empty | Emergencies are warm-transferred here (with a spoken AI summary). |
| `CASE_MANAGER_NUMBER` | no | empty | "I want to talk to a person" is transferred here. |
| `OUTBOUND_ALLOWED_NUMBERS` | for outbound | empty | Comma-separated E.164 numbers AI calls may dial. **Nothing else can be called** (toll-fraud and demo-safety guard). |
| `OUTBOUND_RETRY_MINUTES` | no | `30` | Unanswered/busy outbound calls are retried once after this. |
| `MAX_CONCURRENT_CALLS` | no | `5` | Cap on simultaneous AI phone calls (cost guard); extra inbound callers hear a busy message. |
| `CALL_DATA_RETENTION_DAYS` | no | `30` | Phone transcripts are erased and caller numbers masked after this. |
| `HOTLINE_AGENT` | no | `inbound-hotline` | Agent profile that answers the hotline. |

### E-mail, fax and Letters of Guarantee

| Variable | Required | Default | Purpose |
|---|---|---|---|
| `SENDGRID_API_KEY` | for e-mail | empty | Twilio SendGrid key for replies and letters. Empty = mock outbox (recorded, not sent). |
| `EMAIL_FROM` | no | `claims@demo-assistance.example` | Sender address (must be a verified SendGrid sender). |
| `FOLLOW_UP_REPLY_TO` | no | empty | Reply-To on meeting follow-ups sent from a lead, so a visitor's reply reaches a presenter's own mailbox instead of the no-reply sender. |
| `INBOUND_EMAIL_SECRET` | for inbound e-mail | empty | Secret path segment of the Inbound Parse webhook (`/api/inbound/email/<secret>`). |
| `INBOUND_FAX_SECRET` | for inbound fax | empty | Secret path segment of the fax webhook (`/api/inbound/fax/<secret>`). |
| `FAX_PROVIDER` | no | `mock` | Outbound fax provider (Twilio Programmable Fax was retired in 2021; adapters plug into `src/lib/services/fax.ts`). |
| `LOG_AUTO_APPROVE_LIMIT` | no | `10000` | Letters of Guarantee up to this amount (EUR) are approved and sent without a person when no rule flags them. |
| `LOG_VALID_DAYS` | no | `7` | Validity of a Letter of Guarantee. |

## Environments

| | Development | Production (EC2) | CI (GitHub Actions) |
|---|---|---|---|
| Database | `docker-compose.dev.yml` (host port **5434**) | `db` container, named volume, no host port | service container |
| App | `npm run dev` on :3000 | Docker image behind nginx :80 | built, not served |
| AI | demo provider (or your key) | demo provider unless `AI_API_KEY` set | demo provider |
| Seed | `npm run db:seed` (idempotent) | automatic via `AUTO_SEED=true` | seeded before tests |

A staging environment is a second EC2 host (or compose project) with its own
`.env`; nothing in the code distinguishes staging from production.

## Secret hygiene checklist

- `.env`, `*.pem`, private SSH keys: git-ignored, never committed
- GitHub Actions credentials live only in repository **Secrets** (`EC2_HOST`,
  `EC2_USER`, `EC2_SSH_KEY`, `EC2_HOST_FINGERPRINT`)
- Operator passwords are stored only as scrypt hashes; `SESSION_SECRET` never
  leaves the host
- The Docker image contains no secrets — everything arrives via environment
  at runtime (`.dockerignore` excludes `.env`)
- Rotate `POSTGRES_PASSWORD`, `SESSION_SECRET` and any AI key if a laptop or
  instance is compromised; all are changed in `.env` + `docker compose up -d`
